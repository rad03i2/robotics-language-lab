# Roadmap

## Phase 1 — Foundation

- Add small algorithms in multiple languages.
- Keep each example readable and runnable.
- Document the purpose of every module.

## Phase 2 — Simulation

- Add a simple robot world model.
- Add robot state replay from telemetry logs.
- Add basic obstacle maps and path visualization.

## Phase 3 — ROS 2 Practice

- Expand launch files.
- Add nodes for sensor publishing and command listening.
- Add parameter validation and sample messages.

## Phase 4 — Dashboard

- Add charts for battery, speed, and sensor data.
- Add WebSocket telemetry.
- Add recording and replay mode.

## Phase 5 — Real Hardware Ideas

- Motor calibration checklist.
- Sensor noise testing scripts.
- Safe emergency-stop interface.
